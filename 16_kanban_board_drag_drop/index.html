💡 Machine Coding Drag & Drop Evaluation Checklist:

  • Event Lifecycle: dragstart, dragover, drop, and dragend.
  • Prevent Default: Browsers reject drops by default! Calling e.preventDefault() inside dragover is mandatory.
  • DOM Order vs State Order: Calculating insertion index using e.clientY and element midpoint offsets.
  • State Immutability: Filtering and splicing arrays without directly mutating DOM elements.
